Phần 1: Inline Style - Tiêu đề màu đỏ

Đoạn văn này được định dạng màu cam bằng thuộc tính inline style trực tiếp trên thẻ HTML.

Phần 2: Internal Style - Tiêu đề màu xanh dương

Đoạn văn này được định dạng màu xanh lá bằng Internal CSS nằm trong thẻ <style> ở phần <head>.

Phần 3: External Style - Tiêu đề màu tím

Đoạn văn này được định dạng màu nâu bằng External CSS nằm trong file css/style.css riêng biệt.
